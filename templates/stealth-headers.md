# Stealth headers — per-stack snippets

Generated by `sec-settings stealth on`. These are the snippets you add to your server / CDN /
framework to send `X-Robots-Tag` and optionally deny crawler UAs at the edge. robots.txt alone is
a polite request (honored by reputable crawlers); the edge deny blocks the ones that ignore it.

## HTTP header (add to every response when stealth is on)

```
X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate
```

## HTML <meta> (in <head> — fallback when you can't set headers)

```html
<meta name="robots" content="noindex, nofollow, noarchive, nosnippet, noimageindex">
```

## Express middleware

```js
// Add to your Express app (or individual router)
app.use((req, res, next) => {
  res.setHeader('X-Robots-Tag', 'noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate');
  next();
});
```

## Next.js (App Router)

```ts
// app/layout.tsx — export a metadata object, NOT a robots.ts file (that announces your intent to crawlers)
export const metadata: Metadata = {
  robots: {
    index: false,
    follow: false,
    nocache: true,
    noarchive: true,
    nosnippet: true,
    noimageindex: true,
    notranslate: true,
    googleBot: {
      index: false,
      follow: false,
    },
  },
};
```

Or via middleware.ts (add the header to every response):

```ts
// middleware.ts
import { NextResponse } from 'next/server';
export function middleware() {
  const res = NextResponse.next();
  res.headers.set('X-Robots-Tag', 'noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate');
  return res;
}
```

Block crawler UAs in the same middleware:

```ts
const blockedUAs = ['GPTBot', 'ClaudeBot', 'CCBot', 'PerplexityBot', 'Bytespider', 'Google-Extended', 'Amazonbot', 'cohere-ai', 'Diffbot', 'Scrapy', 'MJ12bot', 'SemrushBot', 'AhrefsBot', 'DotBot'];
const ua = request.headers.get('user-agent') || '';
if (blockedUAs.some(b => ua.includes(b))) {
  return new Response('', { status: 410 });
}
```

## nginx

```nginx
# In server block (or location block for selective pages):
add_header X-Robots-Tag "noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate" always;

# Block crawler UAs:
if ($http_user_agent ~* "(GPTBot|ClaudeBot|CCBot|PerplexityBot|Bytespider|Google-Extended|Amazonbot|cohere-ai|Diffbot|Scrapy|MJ12bot|SemrushBot|AhrefsBot|DotBot)") {
    return 410;
}
```

## Cloudflare

Transform Rule → Modify Response Header → `X-Robots-Tag` = `noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate`.

WAF Custom Rule → `(http.user_agent contains "GPTBot" or http.user_agent contains "ClaudeBot" or ...)` → Block with 410.

## Static hosts (Netlify, Vercel, Cloudflare Pages)

**_headers** (or equivalent — put in public/ or root):
```
/*
  X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate
```

## Honest limits

- robots.txt and noindex are REQUESTS, not enforcement. Reputable crawlers honor them; scrapers and
  aggressive bots may not. Edge-level UA blocking catches more but some spoof UAs.
- Already-indexed pages: Google/Bing need time to re-crawl and remove; this does not remove them
  instantly. For faster removal, use Search Console > Removals (Google) / Bing Webmaster Tools.
- Direct URL access, archive.org snapshots, and screenshots are not affected unless you block
  those UAs too (archive.org_bot is in the list).
- Mobile apps (Expo/React Native) are not crawled — stealth mode has no effect on app stores or
  in-app browsers. App store listings use App Store Connect / Play Console metadata separately.
